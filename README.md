# HapGUI Desktop

Phenotype analysis, GWAS and haplotype-phenotype analysis for rice, as a single Windows app.

**Download:** see the [latest release](../../releases/latest) or the [website](https://irrisouthasiahub.github.io/HapGUI/).

- Windows 10 or 11, 64-bit
- R, Java, PLINK 2, TASSEL and the 3K-RICE data are bundled; nothing else to install
- User manual: [HapGUI_User_Manual.pdf](HapGUI_User_Manual.pdf)
